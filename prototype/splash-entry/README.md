# Breakspider splash entry proof of concept

Open `index.html` in a modern browser. It reuses the current four-second logo animation from `../logo-animation/index.html` and the approved final SVG. No server or package install is needed.

After the animation finishes, **Enter** appears. Click the button or anywhere on the splash to split its two black halves and reveal a placeholder homepage. The seam is aligned to x=750 in the 1600-unit final logo, where the web is broken. Use **Replay intro** on the homepage to reset the study.

The homepage content is deliberately a placeholder. This page tests the splash, the entry moment, and the opening transition. Reduced-motion settings skip the logo playback and shorten the panel movement.
